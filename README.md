# Сайт запису на прийом до лікаря

Простий одностраничний сайт для запису пацієнтів на прийом до лікаря.

## Що є в проекті

- `index.html` — головна сторінка
- `style.css`  — стилі
- `script.js`  — логіка календаря та форми

## Налаштування (обов'язково!)

### 1. Підключення пошти через Formspree

Щоб заявки приходили на вашу пошту:

1. Зайдіть на [formspree.io](https://formspree.io) та зареєструйтесь (безкоштовно)
2. Створіть нову форму → вкажіть вашу email-адресу
3. Скопіюйте ID форми (виглядає як `xbjnkqpo`)
4. Відкрийте `index.html` і знайдіть рядок:
   ```
   action="https://formspree.io/f/YOUR_FORM_ID"
   ```
   Замініть `YOUR_FORM_ID` на ваш реальний ID.

### 2. Персоналізація

Відкрийте `index.html` і замініть:
- `Іванов Олексій Миколайович` → ваше ім'я
- `Терапевт · Кардіолог` → ваша спеціалізація
- Адресу, телефон у секції Контакти

### 3. Налаштування розкладу

Відкрийте `script.js`, знайдіть блок `CONFIG`:

```js
const CONFIG = {
  workDays: [1, 2, 3, 4, 5],   // 1=Пн, 2=Вт, ..., 6=Сб, 0=Нд
  timeSlots: ["09:00", "09:30", ...],  // години прийому
  bookedSlots: []               // вже зайняті слоти
};
```

Додайте зайняті слоти у форматі `"РРРР-ММ-ДД ГГ:ХХ"`:
```js
bookedSlots: ["2025-06-15 10:00", "2025-06-15 11:30"]
```

## Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub
2. Завантажте три файли: `index.html`, `style.css`, `script.js`
3. Перейдіть до Settings → Pages
4. У розділі "Source" оберіть гілку `main` та папку `/ (root)`
5. Натисніть Save — через хвилину сайт буде доступний за адресою:
   `https://ваш-логін.github.io/назва-репозиторію`

## Технології

- Чистий HTML/CSS/JavaScript — без фреймворків
- Формspree — для надсилання заявок на пошту
- Google Fonts (Cormorant Garamond + Inter)
